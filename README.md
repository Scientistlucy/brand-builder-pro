# Rahisi Movers

Website for **Rahisi Movers**, a professional moving and relocation company based in **Nairobi, Kenya**.

## What this site is about

Rahisi Movers helps families and businesses move with a clear process, careful packing, and fixed written pricing. This site is the company’s online home: services, how a move works, work gallery, quotes, FAQs, and contact.

**What it covers**

- **Home moving** — apartments and family homes around Nairobi and beyond  
- **Office moves** — out-of-hours and phased relocations  
- **Packing & storage** — packing-only jobs and short-term storage  
- **International & long-distance** — regional routes with logistics support  

**Base:** Enterprise Road, Industrial Area, Nairobi  

**Built for:** clients who want to understand the offer, get a free estimate, and reach the crew by phone or enquiry form.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:8080`).
